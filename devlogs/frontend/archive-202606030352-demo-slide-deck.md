## 操作步骤

### 1. 大纲 + 定位修正

- 出了精确到每页的大纲（封面/起因/土办法/启发/架构/两个 AI 入口/…）。
- **用户修正定位（重要）**：不是"别让 AI 读、得先沉淀总结"，而是**给 AI 开一条通道、让它主动直接看见你某时某刻在干嘛** —— 核心是"单纯记录 + 高级检索 + 让 AI 来看"，更像给 AI 当**持久记忆层 / 能看屏幕的伙伴**，跟日报定位完全不同。④⑤ 据此重写。

### 2. 框架 + 前几页（暖纸面编辑风，刻意避开 AI slop）

- 建 `demo-slides/` 文件夹 + 单 `index.html`（内联 CSS+JS，键盘 `←→`/空格 + 右下 `‹›` + 顶部进度条，离线可放映，零 CDN）。配色走暖纸面 #f7f4ee + 靛蓝 #5b54e0 + 编辑排版，避开"渐变玻璃风"。

### 3. 逐页迭代（用户每批 review）

- ④ 启发页重写成"日报这事点醒我 → 想让 OpenClaw 主动看见 → 做了 TimeTrace = 老实记录 + 高级检索"，避开对比句式。

### 4. 算法细节页：派 agent 核对真代码（实事求是）

用户明确"得调一个 agent 去专门查代码、实事求是，没写好的用浅色标'施工中'"。→ 并行派 **3 个 Explore agent** 只读核对：搜索/采集/限流重试/自愈/分类/stub 清单。核对结论用于 ⑨–⑫：

- **多模态搜索**：关键词 FTS5 trigram+BM25 ✅、以图搜图 pHash+BK-tree ✅、RRF(k=60) 融合 ✅；**语义向量 embedding+余弦已实现但没接进搜索入口 → 标"施工中"浅色**（`mcp_layer/tools.py` 的 search_activity/get_category_stats 也是 stub）。后又在搜索页右侧空白加 **RRF 公式卡**（score=Σ 1/(k+rank)，k=60）。
- **采集去抖**：切窗等 1.5s 再拍+切换中取消、min 2s、idle 180s 停、30s 补帧。
- **韧性**：outbox append-only+fsync+原子改名+UNIQUE 幂等+重启 at-least-once 重放；队列状态机+reclaim(5min)；限速令牌桶+指数退避 1→60s；worker 重试 5 次 60→600s+熔断(连败3次睡30s探活)。
- **分类**：KNN 已删 → VLM 描述每帧直接选 1 类 + 规则**加权投票**（规则 2.0 > VLM 1.5，确定性覆盖）+ per-app 自定义已接线。

## 遇到的问题与解决

### 问题1：demo-slides 被 gitignore，"commit 在哪里"

**现象：** 用户在主仓库 `git log` 看不到 slide 的提交。
**原因：** 为护隐私把 `demo-slides/` 加进了 `.gitignore`，提交其实在 `demo-slides/.git` 这个**嵌套本地仓库**里。
**解决：** 给用户演示 `git -C demo-slides log` + `remote -v`（无 remote）；后用户确认仓库私有，改为收进主仓库（删嵌套 .git + 取消 ignore + add 全部）。

### 问题2：「不是 X，而是 Y」句式被嫌恶心

**现象：** 封面"不是又一个日报工具，是一层…"被用户指"好恶心"。
**解决：** 删掉；**写进长期记忆 `feedback_no_contrastive_cringe`**——以后禁用"不是X而是Y/与其X不如Y"对比转折句式，直接正面陈述。

### 问题3：算法细节怕吹牛

**现象：** 技术页若凭记忆写，可能把没接线的功能说成做好了。
**解决：** 派 3 个 Explore agent 对着真代码核对，未完成的（语义向量搜索接入、MCP stub）用浅色"施工中"标注，实事求是。

## 知识清单

- **单自包含 HTML deck**：内联 CSS+JS、`.slide{position:fixed;inset:0;opacity 切换}` + 键盘/按钮翻页 + 进度条；离线可放映、零依赖；演示时浏览器滚轮可放大，所以图小一点没关系。
- **实事求是先核码**：做技术演示页前，派 agent 只读核对真实实现，未完成的明确标"施工中"——别人问起来就直说没做好，不怕被问。
- **隐私闸**：提交含敏感截图前**必须 `gh repo view --json visibility,isPrivate` 验证仓库私有**；gitignore 的内容若要版本控制，用"无 remote 的嵌套本地 git 仓库"，要进主仓库时删嵌套 .git + 取消 ignore。
- **反 AI slop 写作**：禁"不是X而是Y"；口语化；用具体工具名（OpenClaw/Hermes/Vanish）而非抽象"AI"。见 [[feedback_no_contrastive_cringe]]。
- **嵌套 git**：主仓库 gitignore 的子目录里建 `git init` 不冲突；但要被主仓库当普通文件跟踪，必须先删子目录的 `.git`（否则 git 视其为 embedded repo 只存 gitlink）。
